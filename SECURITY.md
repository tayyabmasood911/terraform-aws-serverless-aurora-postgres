# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates and patches.

| Version | Supported          |
| :---    | :---:              |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

Security is a foundational tenet of this architecture. If you discover a security vulnerability or potential exposure within this repository, please follow these guidelines:

1. **Do not create a public GitHub issue** describing the vulnerability.
2. Email the maintainer directly at **tayyabmasood911@gmail.com** with details of the findings.
3. Include relevant reproduction steps, affected components, and potential impact.

### Response & Remediation
- You will receive an acknowledgment within **24 hours**.
- A technical assessment and patch remediation will be coordinated in a private fork prior to disclosure.
